# Nguyen Van Bao Digital Platform

## Deploy
1. Push this folder to GitHub and import it into Vercel.
2. Create a Vercel Blob store and connect it to the project.
3. Add Environment Variables: `BLOB_READ_WRITE_TOKEN` and `ADMIN_KEY`.
4. Redeploy.
5. Owner upload page: `/admin.html`. Users see shared files on `/` and can download them.

The music player uses `public/audio/vanbaodev-demo.mp3`. Replace that file with your own audio if desired.
